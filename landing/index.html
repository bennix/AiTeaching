教
教师端

从整学期规划到每周执行

  • 单周 / 整学期教案导入与拆分
  • Markdown 与 LaTeX 教学内容渲染
  • 按题型、题量、难度生成 AI 题库
  • 签到、完成率与知识点掌握图表
  • AI 班级学情报告与个体学习诊断
学
学生端

在浏览器中完成学习闭环

  • 课程、班级与学号登录，无需安装应用
  • 按教学周查看讲义与课程资料
  • 完整显示 Markdown 与 LaTeX 公式
  • 签到、做题、AI 批改与学习诊断

简单但完整

四步跑通一周教学

  1. 01

    导入教案

    接受 PDF、DOCX 与 Markdown，可指定一个教学周或整个学期。

  2. 02

    AI 整理

    按周生成目标、重点难点、教学流程、活动、练习与资源建议。

  3. 03

    教师审核发布

    老师预览、调整并发布题目和资料，始终保留最终决定权。

  4. 04

    学生学习反馈

    学生签到与作答，系统沉淀记录并形成个性化诊断。

Local-first

课堂数据，不必离开你的电脑

应用在本机启动 Node.js 局域网服务。学生通过同一网络中的浏览器进入，课程、名单、提交与签到保存在教师电脑；API Key 使用 AES-256-GCM 加密。
